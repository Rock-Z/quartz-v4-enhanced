# Quartz v4 Enhanced

Some (personal-taste-based) enhancements and bug fixes based on Quartz v4: https://github.com/jackyzha0/quartz

## Changes from upstream Quartz v4

Added a few features/bug fixes, notably:

- Mobile friendly dynamic sidebar/menu sizing and placement.
- Back to top button.
- Forward links panel (in addition to backlinks).
- Added Mermaid diagram interaction support, including pan/zoom behavior.
- Improved LaTeX handling to match obsidian behaviors:
  - Normalizes display math delimiters onto standalone lines.
  - Avoids incorrectly parsing whitespace-padded single-dollar spans and currency-like text as math.
- TOC scrolling.

In addition, I moved graph view as a button in the left instead of a view panel, there might be some other minor layout changes as well.
